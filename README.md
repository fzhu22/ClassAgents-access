# ClassAgents pilot access

Request access to the private Windows pilot using the [request form](https://github.com/fzhu22/ClassAgents-access/issues/new?template=request-access.yml). A GitHub account is required. Your username and request are public. Do not include email addresses, school IDs, course files, passwords or keys.

The owner reviews requests manually. A request or label does not grant access. If approved, accept the invitation to the separate private downloads repository, then [download the installer](https://github.com/fzhu22/ClassAgents-downloads/releases/latest) while signed in. Requests do not grant access to the application source repository.

This repository contains only access instructions and an issue form. No installers, credentials or application source are hosted here.
